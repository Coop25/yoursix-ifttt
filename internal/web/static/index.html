Template help

URL, body, header values, password and messages are Go templates.

  • {{ .data.deviceName }}, {{ .data.siteName }}, {{ .data.videoSourceId }} – event data
  • {{ .event.eventCode }}, {{ .event.eventTopic }}, {{ .event.key }}, {{ .rule }}
  • {{ json .data.deviceName }} – JSON-quoted value for JSON bodies
  • {{ urlquery .data.deviceName }} – URL-escaped value
  • {{ secret "FRONT_CAM_PASS" }} – one of your secrets (Secrets tab), or an operator env secret Y6IFTTT_SECRET_FRONT_CAM_PASS. The name must be a quoted literal.
