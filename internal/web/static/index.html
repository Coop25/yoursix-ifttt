Saved actions

Set up an HTTP request, delay or Discord message once and use it from any rule with + Saved action. Editing it here updates every rule that uses it. Parameters ({{ .params.NAME }}) let each rule fill in its own values, such as a preset name.

Schedules

Days and hours a rule may run, like "Weeknights 22:00–06:00". Pick one in a rule under Only run during; events outside it are logged as off hours and ignored. Editing a schedule updates every rule that uses it.

Your secrets

Encrypted at rest and write-only: once saved, a value can't be viewed again. You can replace or delete it. Only you can see your secrets. Other admins can't see or use them.

Use one in a rule as {{ secret "NAME" }}. A rule runs with the secrets of whoever last saved it, so another admin who edits your rule can't borrow yours.

Template help

URL, body, header values, password and messages are Go templates.

  • {{ .data.deviceName }}, {{ .data.siteName }}, {{ .data.videoSourceId }} – event data
  • {{ .event.eventCode }}, {{ .event.eventTopic }}, {{ .event.key }}, {{ .rule }}
  • {{ json .data.deviceName }} – JSON-quoted value for JSON bodies
  • {{ urlquery .data.deviceName }} – URL-escaped value
  • {{ regexquote .data.deviceName }} – matches the value literally in a regex watch filter
  • {{ .params.preset }} – inside a saved action: a value the rule fills in
  • {{ secret "FRONT_CAM_PASS" }} – one of your secrets (Secrets tab), or an operator env secret Y6IFTTT_SECRET_FRONT_CAM_PASS. The name must be a quoted literal.

Template help

URLs, bodies, header values, passwords and messages are Go templates. They see the triggering event and the parameters:

  • {{ .params.preset }}, {{ urlquery .params.preset }} – a parameter value
  • {{ .data.deviceName }}, {{ .event.eventCode }} – event data, as in rules
  • {{ secret "CAMERA_PASS" }} – one of your secrets. A saved action that uses secrets can only be used by your own rules, because parameters could otherwise redirect it.
